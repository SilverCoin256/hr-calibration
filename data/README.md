# Data

This project uses the **IBM HR Analytics Employee Attrition & Performance** dataset.

Download from Kaggle:
https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

Place the file at `data/raw/ibm_hr_attrition.csv` before running the pipeline.

The dataset is synthetic (generated by IBM data scientists for educational purposes) and contains no real employee records. N = 1,470, 35 columns, binary target `Attrition` (Yes/No).
